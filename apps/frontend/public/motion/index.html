A real spring

Cinematic drives the digits with a damped spring integrated per frame, not a cubic-bezier. The difference only shows when you interrupt it — type fast and each strip carries its existing velocity into the next target instead of restarting from zero.

Fixed 1/120s sub-steps, because a variable frame delta makes a stiff spring explode.

Success as a sequence

Four beats, each waiting on the one before: the rail completes, confirmation travels across the six boxes, the card lifts and blooms, the tick draws. Played together it reads as noise. Played in order it reads as the system finishing something.

Depth, on a mouse only

Cards lean toward the pointer in real perspective with a sheen that tracks it. Bound to (hover: hover) and (pointer: fine) — a card that tilts under a finger is a card that fights scrolling.

Degrading on purpose

The conic focus ring needs @property; without it the box keeps a plain ring. The note reveals use animation-timeline: view() behind an @supports guard; without it they are simply visible. Neither is a broken state.

All three treatments honour prefers-reduced-motion to the same standard: entrances become a plain opacity fade, the spring stops driving, tilt and bloom are dropped, the tick renders already drawn — and the rail still fills, because it carries information rather than decoration.
